# `$channelCategoryID[channelID]`

**Category:** Channels  
**Returns:** The ID of the category that a given channel belongs to.

---

## 📝 Description

This function returns the **category ID** for the specified channel. It can be useful for verifying the organization of channels or referencing a parent category in logic or access controls.

If the channel is not valid or does not belong to a category, it will raise an error.

---

## ⚙️ Usage

```txt
$channelCategoryID[123456789012345678]
```
