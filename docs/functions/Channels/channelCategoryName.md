# `$channelCategoryName[channelID]`

**Category:** Channels  
**Returns:** The **name** of the category that the specified channel belongs to.

---

## 📝 Description

Returns the name of the **category** that contains the specified channel.

This is useful for displaying user-friendly names or organizing commands that respond differently based on category structure.

If no valid channel ID is provided, or the channel doesn't belong to a category, this function will raise an error.

---

## ⚙️ Usage

```txt
$channelCategoryName[123456789012345678]
```
