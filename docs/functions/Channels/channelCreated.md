# `$channelCreated[channelID; timezone?; format?]`

**Category:** Channels  
**Returns:** The date and time a channel was created, formatted to your liking.

---

## 📝 Description

Returns the creation date of the specified channel.  
Optionally supports timezone localization and formatting styles.

You can supply parameters in one of three formats:

### 1. Just the channel ID
```txt
$channelCreated[1234567890]
```
