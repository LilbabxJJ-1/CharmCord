# `$channelDelay[channelID]`

**Category:** Channels  
**Returns:** The slowmode delay (in seconds) set for the specified channel.

---

## 📝 Description

Returns the **slowmode delay** configured for a given channel.  
Slowmode determines how often users can send messages in a channel (e.g., 5s, 30s, etc.).

This is useful for moderation bots or commands that reflect channel settings dynamically.

---

## ⚙️ Usage

```txt
$channelDelay[123456789012345678]
```
