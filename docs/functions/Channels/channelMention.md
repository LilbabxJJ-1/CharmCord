# `$channelMention[channelID]`

**Category:** Channels  
**Returns:** A Discord-formatted channel mention string (e.g., `<#1234567890>`).

---

## 📝 Description

This function returns a **mention** for the specified channel that can be sent in a message.

Mentioning a channel will cause Discord to hyperlink it so users can click and jump to the channel directly.

---

## ⚙️ Usage

```txt
$channelMention[123456789012345678]
```
