# `$channelName[channelID]`

**Category:** Channels  
**Returns:** The name of the specified channel.

---

## 📝 Description

Retrieves the **name** of the provided channel ID. This is helpful for displaying readable channel names in logs, embeds, or messages where a mention is not desired.

This function works with both raw channel IDs and `<#...>` mentions.

---

## ⚙️ Usage

```txt
$channelName[123456789012345678]
```
