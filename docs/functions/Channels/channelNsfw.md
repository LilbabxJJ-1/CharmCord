# `$channelNsfw[channelID]`

**Category:** Channels  
**Returns:** `true` or `false` depending on whether the channel is marked as NSFW.

---

## 📝 Description

Checks if a channel is flagged as **NSFW** (Not Safe For Work).  
This can be useful when:
- Preventing bot responses in adult-marked channels
- Enforcing moderation rules
- Displaying warnings for age-restricted content

---

## ⚙️ Usage

```txt
$channelNsfw[123456789012345678]
```
