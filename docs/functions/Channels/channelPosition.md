# `$channelPosition[channelID]`

**Category:** Channels  
**Returns:** The position (order) of the specified channel in the channel list.

---

## 📝 Description

This function returns the **position index** of a channel within its category or server.  
Channel position determines the order in which channels are displayed in Discord’s UI.

- A position of `0` is the topmost channel in its list.
- Higher values indicate a lower visual placement.

---

## ⚙️ Usage

```txt
$channelPosition[123456789012345678]
```
