# `$channelType[channelID]`

**Category:** Channels  
**Returns:** The type of the given channel (e.g., `text`, `voice`, `category`, etc.).

---

## 📝 Description

Returns the **channel type** of the specified Discord channel.  
Useful for conditional logic when handling commands differently depending on whether the channel is:

- a text channel
- a voice channel
- a forum
- a category
- etc.

---

## ⚙️ Usage

```txt
$channelType[123456789012345678]
```
