# `$channelURL[channelID]`

**Category:** Channels  
**Returns:** A clickable URL that jumps to the specified channel in Discord.

---

## 📝 Description

Generates a **direct Discord link** to the specified channel.  
This is helpful when referencing a channel in messages, logs, embeds, or navigation systems.

When a user clicks the link, Discord will take them directly to that channel.

---

## ⚙️ Usage

```txt
$channelURL[<#123456789012345678>]
```
