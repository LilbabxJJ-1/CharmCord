# 🏰 Guild Functions

Guild functions give you access to information about the server (also known as a "guild") that your command is running in. These are helpful for logging, server-specific logic, statistics, or personalization based on the current Discord guild.

---

## 🧭 Function Index

| Function | Summary |
|----------|---------|
| [`$guildID`](#guildid-no-args) | Returns the ID of the current guild |
| [`$guildName`](#guildname-no-args) | Returns the name of the current guild |
| [`$guildTextChannels`](#guildtextchannels-no-args) | Returns the count of text channels in the current guild |
