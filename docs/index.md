## 📦 Welcome to CharmCord

**CharmCord** is a string-based command framework designed to bring the simplicity and style of scripting languages to Python-powered Discord bots.

Whether you're a beginner who finds Python syntax intimidating, or a power user building fast, flexible command logic — CharmCord gives you an expressive toolkit for building bots with ease.

> 🧙 Think of it like a "magic layer" on top of `discord.py`, transforming raw Python into readable, logic-rich commands like:
>
> <pre> ```
> $if[$args[1]==hello]
>   $sendMessage[$channelID; Hi there!]
> $endIf
> ``` </pre>

---

### 🛠 What Makes CharmCord Special?

* 🧵 **String-based syntax:** Clean, readable, and great for non-coders
* 🔁 **Nested `$if` support:** Full control flow just like a real scripting language
* 📦 **Over 170+ built-in functions:** From sending messages to evaluating Python code
* 🤖 **Powered by `discord.py`:** The power of Python under the hood
* 🧱 **Custom command creation:** Let your users define and save their own commands!
